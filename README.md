# 🧾 حاسبة الأجرة – Fare Split Calculator

**حاسبة الأجرة** هي أداة ويب بسيطة وعملية تساعد المستخدمين على تقسيم المبالغ المالية بين الأشخاص بسرعة ودقة، مع عرض نتائج شاملة وملخص للأموال المحصلة والمتبقية.

تم تطوير المشروع باستخدام **HTML، Bootstrap 5 (RTL)، وFont Awesome** لتوفير واجهة مستخدم حديثة، متجاوبة، وسهلة الاستخدام على جميع الأجهزة، خاصة الهواتف الذكية.

---

## 📌 المميزات الرئيسية

* **تصميم موبايل أولًا (Mobile-First):** تجربة مستخدم سلسة على الهواتف الذكية، قابلة للتوسع للشاشات الأكبر.
* **واجهة مستخدم حديثة ونظيفة:** استخدام Bootstrap لتصميم واضح ومرتب مع أيقونات Font Awesome.
* **إدخال البيانات بسهولة:** حقول الأجرة للفرد، المبلغ الإجمالي، وعدد الأشخاص.
* **عمليات ديناميكية:** إضافة المدخلات ومسحها بسهولة.
* **عرض النتائج بوضوح:** جدول تفاعلي يعرض المبالغ، الأشخاص، الباقي، وحالة التحصيل.
* **ملخص سريع:** يعرض عدد الإدخالات، الأشخاص المحصل منهم، إجمالي المبالغ المتبقية والمحصلة.
* **متجاوب بالكامل:** مناسب لجميع الشاشات (هواتف، أجهزة لوحية، كمبيوترات مكتبية).
* **إمكانية التخصيص بسهولة:** فصل CSS وJS يجعل المشروع قابل للتعديل والتطوير بسهولة.

---

## 🚀 كيفية الاستخدام

1. افتح **index.html** في أي متصفح حديث.
2. أدخل البيانات المطلوبة في الحقول:

   * **الأجرة للفرد**
   * **المبلغ الإجمالي**
   * **عدد الأشخاص**
3. اضغط **إضافة** لتسجيل العملية.
4. يمكن الضغط على **مسح الكل** لإعادة تعيين جميع المدخلات.
5. جدول النتائج سيعرض البيانات مع الملخص في أسفل الصفحة.

## 🎨 المظهر والتصميم

* ألوان هادئة مع تباين جيد لتسهيل القراءة.
* أيقونات توضيحية لكل قسم، للمدخلات، النتائج، والأزرار.
* بطاقات (Cards) مع ظل خفيف لإبراز المحتوى.
* أزرار متجاوبة مع تأثير hover لتحسين تجربة المستخدم.
* جدول النتائج مصمم مع تجاوب تلقائي للشاشات الصغيرة.

## 📐 التوافق والدعم

* متوافق مع جميع المتصفحات الحديثة: Chrome, Firefox, Edge, Safari.

* تصميم متجاوب لجميع الأجهزة (Responsive).

* يمكن تعديل **style.css** لتغيير الألوان والخطوط بسهولة.
